# OstrichLoggers
This repository contains R scripts for the analysis of body temperature data and morphological data of ostrich chicks and some weather data.

01: Filtering and reshaping of ambient temperature data from different loggers
02: Filtering and reshaping of body temperature data
03: Estimating body temperature modes
04: Estimating heterothermy index (HI)
05: Repeatability analysis of morphological measurements
06: Filtering and reshaping morphology data and calculating growth rates
07: Modelling daytime HI
08: Modelling nighttime HI and night and day together
09: Modelling growth and HI
10: Modelling morphology and HI
